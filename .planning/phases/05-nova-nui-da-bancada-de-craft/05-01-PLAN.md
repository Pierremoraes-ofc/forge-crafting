# Plan 05-01: Componentes de Front-End da NUI e Registro no Manifest

## Objetivo
Criar os arquivos de front-end NUI dedicados para a bancada de trabalho (`html/index.html`, `html/css/style.css`, `html/js/app.js`) com visual dark glassmorphism moderno, responsivo e de alta performance, e registrar os assets no `fxmanifest.lua`.

---

## Detalhes das Tarefas

### 1. Registro em `fxmanifest.lua`
- Declarar a página de interface FiveM:
  ```lua
  ui_page 'html/index.html'
  ```
- Declarar os arquivos NUI na tabela `files`:
  ```lua
  files {
      'html/index.html',
      'html/css/**',
      'html/js/**',
  }
  ```

### 2. Estrutura HTML (`html/index.html`)
- Container principal `#crafting-app` inicialmente oculto (`display: none`).
- **Header:**
  - Título da bancada com ícone temático de forja/martelo.
  - Badge do nível de maestria do jogador (`Nível X` ou `Maestria`).
  - Campo de busca `#search-input` para filtragem dinâmica de receitas por nome.
  - Botão fechar `#btn-close` com ícone SVG.
- **Corpo Principal (Duas Colunas):**
  - **Coluna Esquerda (`#recipe-list`):** Lista rolável de receitas com cards compactos contendo ícone do item, nome, tempo e indicador de status (Disponível, Faltam Materiais, Bloqueado por Nível).
  - **Coluna Direita (`#recipe-detail`):**
    - Painel de exibição do produto selecionado: imagem grande, nome, tempo de fabricação e quantidade produzida.
    - Indicador de Maestria Requerida vs Nível Atual.
    - Lista de Insumos Requeridos (`#ingredients-list`): cada ingrediente com ícone, nome e contador `possuído / necessário` com cores dinâmicas (verde quando suficiente, vermelho quando insuficiente).
    - Botão de Ação `#btn-craft`: Botão com efeito de pulso/brilho para "Fabricar Item", ou desabilitado caso não atenda aos requisitos.

### 3. Estilização CSS (`html/css/style.css`)
- Tema escuro imersivo (glassmorphism com fundo semi-transparente, backdrop-filter blur, bordas sutis e acentos em azul metálico/laranja de forja).
- Tipografia moderna (Inter / Segoe UI / sans-serif).
- Scrollbar customizada e elegante para a lista de receitas.
- Animações suaves de transição ao alternar receitas e ao passar o mouse.
- Estados visuais claros para cards disponíveis vs bloqueados.

### 4. Lógica JavaScript (`html/js/app.js`)
- Listener de mensagens NUI `window.addEventListener('message', ...)` para a ação `"open"` e `"close"`.
- Gestão de estado local (lista de receitas, bancada atual, nível do jogador, imagem base).
- Mecanismo de busca e filtro em tempo real sem re-renderização desnecessária.
- Seleção de receita ativa e atualização dinâmica do painel de detalhes.
- Fallback automático para imagens ausentes via SVG inline de item genérico.
- Suporte a tecla `Escape` para fechar a interface.
- Disparo de chamadas `fetch('https://forge-crafting/close')` e `fetch('https://forge-crafting/craft', ...)`.

---

## Critérios de Verificação
- Os arquivos HTML, CSS e JS são válidos sintaticamente.
- O `fxmanifest.lua` carrega a página `html/index.html` e os arquivos estáticos sem erros de sintaxe.
- A interface é oculta por padrão até o recebimento do evento `open`.
