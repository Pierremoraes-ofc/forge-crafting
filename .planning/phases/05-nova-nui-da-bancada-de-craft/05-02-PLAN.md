# Plan 05-02: Integração da NUI com o Client Lua e Pipeline de Fabricação

## Objetivo
Conectar a nova interface gráfica NUI ao ciclo de vida do client Lua no `forge-crafting`, substituindo os antigos menus de contexto pela NUI interativa com sincronização de inventário em tempo real e acionamento seguro do pipeline de crafting.

---

## Detalhes das Tarefas

### 1. Refatoração de `CraftMenu` em `client.lua`
- Quando o jogador interage com uma bancada no mundo (via target `pr_lib.target.addLocalEntity`):
  - Chamar `pr_lib.callback.trigger('forge-crafting:fetchItemsFromId', function(result) ... end, id)`.
  - Para cada receita retornada:
    - Mapear cada ingrediente da receita e consultar a quantidade atual no inventário do jogador usando `pr_lib.inventory.GetItemCount(nil, ingredient.item)`.
    - Calcular se a receita é fabricável pelo jogador (`hasIngredients` e `hasLevel`).
    - Empacotar dados enriquecidos (nome, label, tempo, quantidade, nível requerido, ingredientes com quantidade requerida e possuída, animação e modelo).
  - Obter o nível atual de maestria do jogador via `getCraftingLevel()`.
  - Disparar `SendNUIMessage`:
    ```lua
    SendNUIMessage({
        action = 'open',
        bench = {
            id = id,
            name = name,
            coords = coords,
            objectid = objectid,
            offset = offset,
        },
        items = formattedItems,
        playerLevel = playerLevel,
        imagePath = Config.ImagePath
    })
    ```
  - Ativar foco com cursor: `SetNuiFocus(true, true)`.

### 2. Implementação dos NUI Callbacks (`client.lua`)
- **Callback `close`:**
  - Desativa o foco: `SetNuiFocus(false, false)`.
  - Retorna `cb({ ok = true })`.
- **Callback `craft`:**
  - Recebe os dados da receita selecionada enviados pelo front-end.
  - Desativa o foco: `SetNuiFocus(false, false)`.
  - Dispara o evento de fabricação autoritativo `TriggerEvent("forge-crafting:CraftCertainItem", craftData)`.
  - Retorna `cb({ ok = true })`.

### 3. Blindagem de Foco e Limpeza no `onResourceStop`
- Garantir que se o recurso for reiniciado ou parado enquanto a NUI estiver aberta, `SetNuiFocus(false, false)` e `SendNUIMessage({ action = "close" })` sejam executados imediatamente, prevenindo que o cursor do FiveM fique travado na tela do jogador.

---

## Critérios de Verificação
- A interação no target de uma bancada abre a nova NUI customizada sem abrir menus de contexto ox/pr_lib legados para os jogadores normais.
- A NUI exibe as receitas com as quantidades de itens reais do inventário do jogador.
- Pressionar ESC ou clicar em Fechar fecha a NUI e restaura os controles e câmera do jogador.
- Clicar em Fabricar fecha a NUI e executa com sucesso o pipeline da Fase 4 (StartCraft -> pr_lib.progressBar -> FinishCraft -> entrega do item).
