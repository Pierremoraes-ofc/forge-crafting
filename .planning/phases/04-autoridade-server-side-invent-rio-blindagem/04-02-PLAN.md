# Plan 04-02: Conexão do Client, Temporizadores com pr_lib.progressBar, Animações e Feedback

## Objective
Refatorar a rotina do cliente `forge-crafting:CraftCertainItem` em `client.lua` para operar exclusivamente através dos callbacks seguros de sessão (`StartCraft`, `FinishCraft`, `CancelCraft`), exibindo temporizadores nativos via `pr_lib.progressBar`, executando animações e limpando adereços temporários.

## Proposed Changes

### 1. Refatoração de `forge-crafting:CraftCertainItem` (`client.lua`)
- Chamar `pr_lib.callback.trigger('forge-crafting:StartCraft', function(success, message, craftData) ... end, data.craft_id, data.craft_item)`.
- Se falhar (`success == false`):
  - Exibir notificação de erro com a mensagem do servidor (`pr_lib.notifications.Notify`).
  - Fechar câmera de pré-visualização (`toggleCam(false)`).
  - Deletar prop temporário de preview caso exista.
  - Abortar a ação.

- Se autorizado com sucesso:
  - Definir `isBusy = true` e fechar câmera de pré-visualização.
  - Tratar animação do jogador:
    - Se houver animação configurada na receita (`craftData.anim`):
      - Verificar suporte a dicionário/clip nativo ou comando de emote.
    - Se não houver, executar animação padrão de oficina (`mini@repair` / `fixing_a_ped`).
  - Disparar a barra de progresso nativa:
    ```lua
    local completed = pr_lib.progressBar({
        duration = (craftData.time or 5) * 1000,
        label = locales.craftingg .. (craftData.item_label or data.item_label),
        useWhileDead = false,
        canCancel = true,
        disable = {
            car = true,
            move = true,
            combat = true,
            mouse = false
        }
    })
    ```
  - Limpar animações do ped (`ClearPedTasksImmediately(ped)`).
  - Definir `isBusy = false`.

### 2. Tratamento de Conclusão e Cancelamento (`client.lua`)
- Se `completed == true`:
  - Acionar `pr_lib.callback.trigger('forge-crafting:FinishCraft', function(finished, finishMsg) ... end)`.
  - Tocar efeito sonoro de sucesso (`PlaySoundFrontend(-1, "PICK_UP", "HUD_FRONTEND_DEFAULT_SOUNDSET", 1)`).
  - Deletar prop de preview `CRAFTABLE_OBJ`.
- Se `completed == false` (jogador cancelou com tecla, morreu ou se moveu):
  - Acionar `TriggerServerEvent('forge-crafting:CancelCraft')` para que o servidor realize o estorno imediato dos materiais consumidos.
  - Exibir notificação informativa de cancelamento e reembolso.
  - Deletar prop de preview `CRAFTABLE_OBJ`.

## Verification Plan

### Automated / Code Inspection
- Verificar ausência de chamadas a `ItemInterval`.
- Confirmar uso estrito de `pr_lib.progressBar` com opções completas de trava de movimento e combate.
- Garantir que a entrega de itens é disparada unicamente após a resposta positiva de `FinishCraft`.

### Manual / In-Game Verification
- Iniciar uma fabricação de item em uma bancada no FiveM.
- Verificar a exibição suave da barra de progresso do `pr_bridge` e animação do personagem.
- Pressionar ESC durante o craft e verificar se a barra é interrompida e se os insumos retornam ao inventário.
- Aguardar o término normal e verificar entrega correta do item no inventário e notificação de sucesso.
