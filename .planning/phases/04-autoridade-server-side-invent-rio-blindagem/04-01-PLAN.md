# Plan 04-01: Backend Autoritativo de Crafting e Sessões Seguras

## Objective
Eliminar o evento vulnerável `forge-crafting:ItemInterval` e criar um pipeline autoritativo de crafting no servidor via callbacks, validando proximidade da bancada, posse da receita oficial, maestria/nível, consumo atômico de materiais e entrega segura pós-verificação de tempo.

## Proposed Changes

### 1. Expurgo de `forge-crafting:ItemInterval` (`sv_utils.lua`)
- Excluir o registro `RegisterNetEvent("forge-crafting:ItemInterval")` que aceitava `"add"` arbitrário vindo de clientes.

### 2. Gerenciador de Sessões de Crafting (`sv_utils.lua`)
- Criar a tabela `activeCraftSessions = {}`.
- Registrar callback `forge-crafting:StartCraft(source, craft_id, item_name)`:
  - Validar jogador (`pr_lib.framework.GetPlayer(src)`).
  - Validar existência da bancada no cache de bancadas (`workshops`).
  - Checar distância física: `#(GetEntityCoords(GetPlayerPed(src)) - benchCoords) <= 4.0`. Se estiver longe, rejeitar com mensagem de distância.
  - Checar permissões de cargo/gangue da bancada (`v.jobenb`), validando o player no servidor.
  - Carregar receita autoritativa no banco (`SELECT * FROM forge-crafting-items WHERE craft_id = ? AND item = ?`).
  - Se a receita exigir `level`, checar com `forge-reputation` se o player possui o nível necessário.
  - Decodificar ingredientes e verificar quantidades no inventário (`pr_lib.inventory.GetItemCount`). Se faltar algum item, rejeitar com erro amigável.
  - Consumir imediatamente os ingredientes via `pr_lib.inventory.RemoveItem`.
  - Registrar a sessão:
    `activeCraftSessions[src] = { craft_id = craft_id, item = item_name, amount = recipeRow.amount, duration = recipeRow.time, consumed = consumedList, startTime = GetGameTimer() }`.
  - Retornar sucesso com os dados de animação, modelo e duração para o cliente.

### 3. Finalização e Cancelamento Autoritativo (`sv_utils.lua`)
- Registrar callback `forge-crafting:FinishCraft(source)`:
  - Verificar existência da sessão ativa para `source`.
  - Validar tempo decorrido: `GetGameTimer() - session.startTime >= (session.duration * 1000 - 1500)`. Se o cliente tentar adiantar ou hackear o tempo, cancelar sem entregar item.
  - Validar proximidade com a bancada.
  - Entregar o item fabricado: `pr_lib.inventory.AddItem(src, session.item, session.amount)`.
  - Premiar experiência via `forge-reputation`: `addCraftingSkill(src)`.
  - Limpar a sessão ativa.
  - Retornar sucesso ao cliente com notificação.

- Registrar callback ou evento `forge-crafting:CancelCraft(source)`:
  - Se houver sessão ativa para `source`, devolver todos os itens consumidos:
    `for _, ing in ipairs(session.consumed) do pr_lib.inventory.AddItem(src, ing.item, ing.amount) end`.
  - Limpar a sessão ativa.

- Registrar listener para `playerDropped`:
  - Se o jogador desconectar durante o craft, devolver os insumos consumidos ao inventário e desalocar a sessão.

## Verification Plan

### Automated / Code Inspection
- Garantir que `forge-crafting:ItemInterval` não existe mais em nenhum arquivo do resource.
- Verificar se `forge-crafting:StartCraft` e `forge-crafting:FinishCraft` estão devidamente registrados com callbacks de `pr_lib.callback`.
- Confirmar que o servidor não aceita parâmetros de quantidade/item forjados pelo cliente para entrega.

### Functional Verification
- Iniciar um craft no jogo e verificar no banco/log o consumo dos materiais.
- Tentar cancelar na metade do tempo e confirmar que todos os materiais são estornados ao inventário.
- Aguardar o término do tempo e confirmar que o item final é entregue sem erros.
