# Plan 03-02: Comandos Nativos de Administração, Permissões ACE e Notificações

## Objective
Registrar os comandos administrativos `/create` e `/edit` de forma autoritativa no servidor com checagens ACE nativas do `pr_bridge`, padronizar as mensagens de notificação no cliente e no servidor e auditar o arquivo `shared/locales.lua`, adicionando todas as chaves em falta e corrigindo divergências.

## Proposed Changes

### 1. Comandos Administrativos com Permissões ACE (`sv_utils.lua`)
- Registrar comandos administrativos no servidor:
  - `Config.CreateTableCommand` (ex: `/create` ou `craft:create`).
  - `Config.EditMenuCommand` (ex: `/edit` ou `craft:edit`).
- Validar se o jogador emissor possui autorização:
  - `source == 0` (Console RCON).
  - `IsPlayerAceAllowed(source, 'command.create')` / `IsPlayerAceAllowed(source, 'command.edit')`.
  - `IsPlayerAceAllowed(source, 'admin')` ou `IsPlayerAceAllowed(source, 'crafting')`.
- Se autorizado: disparar o evento cliente correspondente (`forge-crafting:CreateMenu` ou `forge-crafting:EditMenu`).
- Se não autorizado: enviar notificação de erro imediata via `pr_lib.notifications.NotifyPlayer`.

### 2. Padronização de Notificações (`cl_utils.lua` e `sv_utils.lua`)
- No cliente (`cl_utils.lua`):
  - Centralizar na função `notify(title, message, msgType)` chamando estritamente `pr_lib.notifications.Notify({ title = title, description = message, type = msgType })`.
- No servidor (`sv_utils.lua`):
  - Centralizar em `serverNotification(source, title, message, msgType)` chamando estritamente `pr_lib.notifications.NotifyPlayer(source, { title = title, description = message, type = msgType })`.
  - Substituir qualquer `print` solto de erro ou alerta de jogador por `serverNotification`.

### 3. Auditoria e Padronização de Idiomas (`shared/locales.lua`)
- Adicionar chaves ausentes que geravam texto `nil`:
  - `press_edit_item = "Clique para editar as opções deste item."`
  - `delete_item = "Excluir Item"`
  - `desc_deleting_item = "Exclui este item de fabricação permanentemente."`
  - `sure_delete_item = "Tem certeza que deseja excluir o item "`
  - `craft_items_amount = "Quantidade Fabricada"`
  - `craft_time = "Tempo de Fabricação (segundos)"`
  - `how_many_items = "Qtd. de Itens Ingredientes na Receita"`
  - `item_model = "Prop 3D do Item (opcional)"`
  - `item_anim = "Dicionário/Nome de Animação (opcional)"`
  - `item_level = "Nível Mínimo de Crafting (opcional)"`
  - `insufficient_permission = "Você não possui permissão para acessar esta ferramenta."`
- Corrigir strings com erros ou inconsistências (ex: `desc_displayname_item = "Alterar nome de exibição do item."`).

## Verification Plan

### Automated / Code Inspection
- Verificar ausência de strings `nil` em chamadas `locales.*`.
- Confirmar que todos os comandos administrativos no servidor checam ACE antes de disparar eventos para o cliente.
- Confirmar que todas as notificações utilizam `pr_lib.notifications.Notify` e `pr_lib.notifications.NotifyPlayer`.

### Manual / In-Game Verification
- Tentar executar `/create` e `/edit` com um jogador sem permissão ACE e verificar se a mensagem de erro é exibida sem abrir a interface.
- Conceder permissão ACE (`add_ace group.admin command.create allow` ou `add_principal identifier.fivem:xxx group.admin`) e verificar abertura imediata do menu.
- Verificar exibição de todas as notificações visuais com títulos, textos completos e ícones corretos.
