# Plan 03-01: Menus Administrativos, Contextos e Diálogos com pr_lib

## Objective
Refatorar integralmente a interface de administração de bancadas e receitas em `cl_utils.lua` para os componentes nativos de contexto e diálogo do `pr_bridge`, garantindo navegação com botão de retorno, formulários limpos via `pr_lib.inputDialog` e confirmações de exclusão seguras via `pr_lib.alertDialog`.

## Proposed Changes

### 1. Refatoração de Menus em `cl_utils.lua`
- **Menu Principal (`crafting_list` / `forge-crafting:EditMenu`):**
  - Exibir opção no topo para criar nova bancada (`forge-crafting:CreateMenu`).
  - Listar bancadas cadastradas com ícone, metadados (ID, Cargos) e seta de navegação (`arrow = true`).
  - Ao selecionar uma mesa, abre o menu de ações específicas (`edit_opcije`).

- **Menu de Edição da Bancada (`edit_opcije` / `forge-crafting:OpenEditFunctions`):**
  - Definir `menu = 'crafting_list'` para permitir retorno ao menu anterior.
  - Opções padronizadas com ícones FontAwesome modernos:
    - *Alterar Nome*: `pr_lib.inputDialog` -> `pr_lib.alertDialog` de confirmação -> `forge-crafting:ChangeName`.
    - *Ajustar Altura/Offset*: `pr_lib.inputDialog` com limites `min = -5.0, max = 5.0, step = 0.05` -> `forge-crafting:UpdateHeight`.
    - *Posicionar no Mundo*: Chama o Gizmo 3D (`updateModelPosition`) implementado na Fase 2.
    - *Gerenciar Itens & Receitas*: Abre submenu `items_list_menu`.
    - *Configurar Permissões (Jobs/Gangs)*: Abre submenu `job_options_menu`.
    - *Configurações de Blip*: Abre submenu `blip_settings_menu`.
    - *Teleportar para Mesa*: Teleporta o administrador até o prop da mesa.
    - *Excluir Bancada*: `pr_lib.alertDialog` com botão de confirmação e cancelamento -> `forge-crafting:DeleteTable`.

- **Gerenciamento de Itens e Receitas:**
  - *Adicionar Novo Item*: Formulário completo via `pr_lib.inputDialog` (seleção de item com busca, rótulo, quantidade final, tempo de preparo, prop, animação opcional, nível mínimo opcional).
  - *Configuração Sequencial de Receita (`createRecipe`)*: Dialogs numerados `(1/N)` para definição dos ingredientes necessários e quantidades.
  - *Submenu do Item Cadastrado*:
    - Alterar tempo de preparo (`inputDialog`).
    - Alterar receita / ingredientes (`createRecipe`).
    - Alterar rótulo de exibição (`inputDialog`).
    - Alterar quantidade recebida (`inputDialog`).
    - Alterar modelo/prop (`inputDialog`).
    - Alterar animação (`inputDialog`).
    - Alterar nível mínimo exigido (`inputDialog`).
    - Excluir item permanentemente (`pr_lib.alertDialog`).

- **Gerenciamento de Permissões de Cargos/Gangues:**
  - Adicionar/Alterar jobs com busca múltipla (`multi-select`) a partir dos dados retornados por `forge-crafting:fetchJobs`.
  - Remover restrição (tornar a bancada pública para todos os cidadãos).

### 2. Cancelamentos e Retornos Suaves
- Garantir que qualquer cancelamento em dialogs (`if not input then return end`) reabra o menu de contexto pai apropriado, evitando que a tela se feche subitamente e deixe o administrador sem ação.

## Verification Plan

### Automated / Code Inspection
- Verificar chamadas diretas a `pr_lib.RegisterContext`, `pr_lib.showContext`, `pr_lib.inputDialog` e `pr_lib.alertDialog`.
- Garantir que nenhum resquício de `lib.` isolado ou bibliotecas legadas exista.
- Verificar consistência dos IDs de menu para navegação reversa.

### Manual / In-Game Verification
- Abrir `/edit`, navegar entre as opções de edição de uma bancada.
- Criar e editar uma receita de teste, alterando insumos, tempo e nível.
- Cancelar uma exclusão no diálogo de alerta e verificar se o menu anterior é restaurado.
- Confirmar exclusão de um item e verificar atualização imediata no banco e na lista.
